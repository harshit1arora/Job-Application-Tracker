# 🚀 Job-Application-Tracker

An autonomous AI Job Application Tracker platform designed to monitor career sites, tailor résumés, submit applications automatically, and track responses in a unified dashboard.

## 📂 Repository Structure

- **`Frontend/`**: Modern React 19 + TanStack Start single-page landing application & web app interface featuring Light/Dark mode, ATS platform integration showcase, interactive pipeline visualizer, and responsive UI components.

For detailed frontend features, architecture, and setup instructions, see [Frontend/README.md](file:///c:/Users/harsh/Downloads/jobpilot-agent-main/jobpilot-agent-main/Frontend/README.md).

## 🌐 Deploy to Vercel

1. Import this repository in your **Vercel Dashboard**.
2. **Root Directory**: Set to `Frontend` (or leave default root as `vercel.json` is provided).
3. **Framework Preset**: `Vite` (automatically detected).
4. Click **Deploy**.
