# 🚀 AI-Job-Application-Tracker

An autonomous AI Job Application Tracker platform designed to monitor career sites, tailor résumés, submit applications automatically, and track responses in a unified dashboard.

## 🚀 Quick Start (Run Locally)

If you downloaded the ZIP file or cloned this repository:

1. **Open terminal in the `Frontend/` folder**:
   ```bash
   cd Frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **(Optional) Setup Firebase for Google Auth**:
   If you want to use Google Authentication, copy the example environment file and add your Firebase credentials:
   ```bash
   cp .env.example .env
   ```
   *(Note: The app works 100% out of the box with **1-Click Demo Login** and **Email & Password Authentication** even without `.env`!)*

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Navigate to [http://localhost:5173](http://localhost:5173)

---

## 🌐 Deploy to Vercel

1. Import this repository in your **Vercel Dashboard**.
2. **Root Directory**: Set to `Frontend` (or leave default root as `vercel.json` is provided).
3. **Framework Preset**: `Vite` (automatically detected).
4. Click **Deploy**.
